Site Pulse 1.3.9 — 网站每日检查工具
==========================================

功能
- 每天自动检查：网站能否打开、响应时间、SSL 证书到期、域名到期、robots.txt、sitemap、ads.txt
- Google Analytics (GA4)、Search Console（含站点地图状态、重要页面收录检查）、AdSense（账号 / 网站状态、提醒、政策问题、收入）、Bing Webmaster
- 每条提醒都写明来源（AdSense / Search Console / 网站检查…）、影响范围、怎么处理，并有按钮直接打开对应后台；不需要处理的可以“忽略”
- 异常提醒：指标比前 7 天平均下降超过设定比例（默认 30%）、网站打不开、证书 / 域名快到期、ads.txt 错误、页面未收录、授权过期等
- 对比：同一指标按网站对比（7 / 28 / 90 天）；关键词（Search Console 搜索词与上一周期对比、按天图表）；导入 Google Trends CSV 并与搜索词点击一起看
- 界面：English / 한국어 / 中文

1.3.0 新功能
- AdSense 审核清单：必备页面（隐私政策 / 关于 / 联系）、文章数量和字数、未完成页面、导航、手机适配、ads.txt、收录……每项 ✓ / ✗ 并写明怎么改
- 页面 → 收录跟踪：从 sitemap 找出新页面，每天检查 Google 是否收录；一键去 Search Console 请求收录
- IndexNow：把新页面马上通知 Bing / Naver 等（需要把一个密钥文件上传到网站根目录，页面里有步骤）
- 页面 → 断链检查：每周检查所有页面和链接，列出 404、多次跳转、很慢的页面以及它们出现在哪里
- 关键词 → 跟踪的关键词：点 ☆ 每天记录排名，掉 3 名以上提醒
- 页面 → 热门页面：按浏览量 / Google 点击排序，看上升和下降最多的页面
- 页面速度（PageSpeed 手机 / 电脑分数、LCP / INP / CLS）和首页响应时间拆分（网络 / 服务器 / 下载）
- 报告：每周一生成上周周报，可打印 / 另存为 PDF，或下载 Excel

1.3.9
- 修复“第一次打开没有画面，要再点一次”：程序启动 Chrome 时带了“隐藏窗口”标志（本来是为了不弹黑色命令行窗口），Chrome 刚启动时的第一个窗口照着这个标志隐藏了。现在不再带这个标志；万一窗口仍是隐藏的，程序也会把它显示出来

1.3.8
- 新功能：设置 → 迁移到另一台电脑。把设置和密钥（网站、检查时间、忽略的提醒、跟踪关键词、OAuth 客户端、Bing / PageSpeed / IndexNow 密钥）保存成一个 .sitepulse 文件，在另一台电脑导入
  - 文件用你自己设的密码加密（AES-256-GCM，PBKDF2-SHA256 60 万次），没有密码打不开，改动过的文件也会被拒绝
  - 可选：同时包含 Google 登录（默认不包含，在新电脑上登录一次更安全）、历史数据（默认包含）
- 修复：第一次打开时窗口看不到（开在其他窗口后面 / 最小化 / 在屏幕外）。窗口连上后程序会主动把它恢复并放到最前面，日志记录 “window to front: …”

1.3.7
- 新功能：页面 → Google Search Console。出现新页面时，每天检查会自动向 Google 重新提交站点地图（每天最多一次），也可以点“지금 사이트맵 다시 제출”手动提交
  * 需要 Search Console 管理权限：升级后到页面 → Google Search Console 点“Google 다시 로그인”，登录一次并允许（其他功能仍只读）
  * Google 不提供普通页面“请求编入索引”的 API，所以单个页面仍要在 Search Console 里点
- 修复：页面列表里的“색인 요청”按钮打开后是 404（Search Console 改了网址格式）。现在点按钮会复制页面地址并打开 Search Console，粘贴到顶部搜索框回车即可；另有“미색인 주소 모두 복사”
- 修复：AdSense 审核清单把标签列表（如 /archive/?tag=privacy）当成隐私政策页。现在跳过标签、归档和带 ? 参数的链接，优先找网址里带 privacy 的页面
- 修复：PageSpeed 偶尔报 NO_FCP 等一次性错误。现在会自动重试一次；还是失败时只显示为“信息”，不再算警告
- 修复：Search Console / Bing 最近 2～3 天的数据还没统计完，以前会误报“曝光大幅下降”。现在只比较已经统计完的日子

1.3.6
- 修复：页面速度（PageSpeed）报 NO_FCP。首页是按语言跳转的页面，自己不显示内容就跳走了；现在测跳转后的页面（例如 /en/）
- 修复：断链检查把 Cloudflare 的邮箱保护链接（/cdn-cgi/l/email-protection）当成 404。这个链接在浏览器里由脚本还原成邮箱，访客点击是正常的，现在不再检查

1.3.5
- 修复：打开后窗口马上自动关闭。原因是以前版本留下的隐藏窗口每 3 秒重新连接一次，把新窗口“顶掉”了
- 现在每次打开的窗口都有自己的编号，只有最新打开的窗口算数；旧窗口 / 隐藏窗口会被告知关闭，且不再重连
- 关闭窗口后约 5 秒自动退出（不变）

1.3.4
- 第一次双击时窗口会被压在其他窗口后面、看起来“没反应”的问题：现在允许 Chrome 窗口跳到最前面
- 只保留一个窗口：再打开一次时，旧窗口会自动断开并提示“已在另一个窗口打开”。以前藏在后面的旧窗口会让程序一直留在后台
- 关掉窗口后约 5 秒程序退出（正在检查时先做完再退）

1.3.3
- 首页用 JS 按浏览器语言跳转（如 location.replace("/" + lang + "/")）时，跟着 hreflang（优先 x-default）找到真正的首页再检查；以前会停在跳转页，误报“没有菜单 / 隐私 / 关于 / 联系链接”
- 审核清单的文章抽样排除 /2/、/ko/3/ 这类数字分页列表页（以前会被当成“内容太短”）
- “首页已被 Google 收录”检查跳转后的真正首页，不再检查跳转页本身

1.3.2
- AdSense 审核清单：每项写明判定标准；可以“打印 / 另存为 PDF”或下载 Excel
- 首页用页面内跳转（如 Astro 的 / → /ko/）时也能正确找到隐私 / 关于 / 联系页面；找不到时再看 sitemap

- Windows：双击 “Site Pulse.exe”。优先用 Chrome，其次 Edge，以独立窗口打开；关掉窗口程序就退出。
- Mac：解压 Site-Pulse-Mac.zip，把 “Site Pulse.app” 放进“应用程序”。第一次打开如果提示“无法验证开发者”：
  右键 → 打开；如果仍然打不开，到 系统设置 → 隐私与安全性 → 点“仍要打开”。
- 程序只在本机 127.0.0.1:17380 运行（被占用时自动换下一个端口），外部访问不到。

第一次设置（设置页面）
1. 导入 OAuth 客户端 JSON（Google Cloud 项目 site-monitor 里“桌面应用”客户端下载的文件）
2. 用 Google 登录 → 出现“Google 尚未验证此应用”时点 高级 → 继续（这是你自己的应用，只读权限）
3. 添加网站 → 点“刷新列表”“自动匹配”选好 Search Console、GA4、AdSense、Bing → 保存
   * 网址带路径（如 https://toolboxnotes.com/ko/）时，Search Console 和 GA4 只统计这个路径下的页面；
     AdSense 和 Bing 只能按整个域名统计
4. （可选）Bing Webmaster Tools → 设置 → API 访问 → 生成 API 密钥，填进来
5. 每日检查时间、提醒比例：默认 09:00、30%

每天检查的时机
- 程序开着时：每天到了设定时间后检查一次
- 当时没开：下次打开时马上补查
- 第一次检查会补拉最近 90 天数据，之后每次重新读取最近 10 天（Search Console 数据有 2–3 天延迟）

数据保存位置（全部在本机）
- Windows：%APPDATA%\Site Pulse
- Mac：~/Library/Application Support/Site Pulse
  config.json（设置，含 OAuth 客户端）、token.json（Google 登录）、metrics.json（每日数据）、
  runs\日期.json（每天的检查结果）、trends.json（导入的 Trends 数据）、Browser-chrome 等（独立浏览器配置，每个浏览器一个）
- 换电脑时复制这个文件夹即可；要彻底清除就删除它

源码
- site-pulse-src.zip：Go 1.24 标准库，无第三方依赖。重新打包：./build.sh
